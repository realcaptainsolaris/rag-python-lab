Device naming FAQ

Why did a rename not change the identifier?

A display name is an editable label for people. A device_id identifies the registration used by measurement records. Renaming a label does not rewrite the registration or move history to a new physical unit. Use the inventory to decide whether a replacement needs a separate registration.

Two devices can have similar display labels while remaining distinct. Do not build an integration join on a label copied from a dashboard screenshot. Keep the returned device_id and the workspace with any external inventory mapping.

Can I reuse a local inventory name?

The external identifier is unique by workspace_id plus external_id. The same inventory name in two workspaces identifies two registrations. If a local inventory system supplies an identifier longer than 64 characters, choose and document a stable mapping instead of silently truncating it.

A collision caused by truncation can send observations to the wrong registration. Validate the mapping over the complete inventory before rolling it out. Correcting one display label afterwards does not undo incorrectly associated observations.

Should a missing device be registered again?

First check which workspace the client is using. A valid token can point at a different workspace from the one currently visible in the browser. If the registration exists there, reconcile the configuration rather than creating a second device.

A missing read permission can also make an existing device appear unavailable to a particular client. Keep absence, permission failure and lifecycle state separate in diagnostic messages. The repair depends on which condition actually occurred.
