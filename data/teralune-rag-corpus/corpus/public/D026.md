# Webhook secret rotation

## Prepare the receiver

A subscription may have at most 2 active signing secrets. During rotation, the overlap lasts 120 minutes. The request header X-Orbit-Key-ID identifies the signing key. Select the intended verifier from this identifier; do not try an unlimited historical list until a signature happens to match.

Deploy support for the replacement secret to every receiver instance before activating it on the sender. A load balancer can alternate between an updated and an outdated instance, producing a pattern that looks like intermittent signature corruption. Keep receiver configuration versions visible in logs without exposing the secret material.

## Verify bytes before parsing

The signature header is X-Orbit-Signature and the algorithm is HMAC-SHA256. Verify the exact raw body before decoding JSON. A proxy that decompresses, reserializes or prettifies the body changes the bytes and invalidates the signature.

Retain the selected key identifier and verification outcome, not the secret. If verification fails only on one path through the infrastructure, compare middleware behavior before rotating again. Creating a third key is not a repair for a receiver that has already changed the payload.

Receiver boundary pseudocode:

```text
key_id = request.header("X-Orbit-Key-ID")
key = configured_active_key(key_id)
raw_body = request.unmodified_bytes()
expected = HMAC_SHA256(key, raw_body)
compare_signature_before_json_decode(expected)
```

The active-key lookup must not fall back to an arbitrary archived secret.

## Complete the overlap

After the overlap ends, remove the previous secret from the receiver and confirm that all instances have reloaded. Old deliveries that are retried after rotation are signed with the active sender key at attempt time. Do not keep an obsolete secret indefinitely merely because the event was created earlier.

Keep secret rotation separate from OAuth credential rotation. Signing verifies an incoming callback; OAuth authorizes API calls to Orbit. A valid callback signature does not grant permission to create exports or change a workspace. Record the two changes in separate deployment steps.
